Description
===========

Este módulo interpõe um campo ``fields.Json`` chamado ``tax_data`` entre os 26
campos-fonte e os ~143 campos de resultado do mixin ``l10n_br_fiscal.document.line.mixin``.

Arquitetura em 2 estágios::

    ANTES: 26 fontes  →  143 campos stored  (3.718 trigger entries)
    DEPOIS: 26 fontes →  1 tax_data  →  143 campos  (169 entries, -95.5%)

Fase 1 (MVP): todos os campos individuais continuam ``store=True``.
Zero risco de perda de dados, zero mudança em SQL reports.
